# Dataset Card

## Built-in synthetic dataset

The default dataset is generated by `src/synthetic_data.py`. It contains synthetic participant-day rows with plausible associations among sleep, activity, stress, HRV, screen time, medication adherence, anxiety, energy, and mood.

The generator is transparent and deterministic when a seed is provided. It is not intended to represent real clinical causal effects.

## Public dataset adapter

The repository includes an adapter for the public Dryad IFH Affect dataset:

```text
https://datadryad.org/dataset/doi:10.7280/D1WH6T
```

The adapter converts participant folders into the MoodTwin daily schema. It derives a demo mood proxy from daily EMA positive/negative affect balance and merges Oura-derived activity, sleep, and readiness information where available.

## Personal data

Personal wearable exports should remain local. Do not commit private Apple Health, Oura, Fitbit, or mood diary files to GitHub.

## Target label

`mood_score` is a 1-10 self-report or demo proxy. It is not a diagnostic label.
